# skill-dipartimento

Repository di prova per la lezione su Git del 10 novembre 2026. Persone, skill e dati sono inventati.

## Cosa c'è

Una cartella per ogni skill, con dentro il file `SKILL.md`:

- `punto-settimanale`: prepara il punto del lunedì dagli appunti della settimana.
- `modulo-bando`: compila la sezione "Risultati attesi" del modulo di un bando.
- `verbale-riunione`: scrive il verbale di una riunione dalla trascrizione.

## Come si propone una modifica

1. Create un branch con un nome che dica cosa cambia.
2. Modificate il file della skill, o aggiungete una cartella nuova.
3. Aprite una pull request: perché, cosa cambia, cosa non cambia.
4. Un'altra persona la rivede. Dopo l'approvazione si fa il merge e la modifica arriva a tutti.
